# Molecular Foundry

**Attribution.** This codebase is derived from [Ben Schrauwen](https://github.com/benschrauwen)'s unofficial MIT-licensed [`terraform-simulator`](https://github.com/benschrauwen/terraform-simulator) ([terraform-simulator.com](https://terraform-simulator.com/)). It is an independent educational tool and is not affiliated with Terraform Industries.

An unofficial, MIT-licensed browser app for exploring coupled industrial processes. The main product is Molecular Foundry, a flowsheet workspace for connecting process blocks and inspecting material and energy flows.

The app is intentionally centered on the idea that very cheap local solar DC, low-capex intermittent hardware, and colocated conversion can matter more than chasing maximum utilization or maximum electrical efficiency.

## Current Foundry State

The root app now provides:

- A blank, editable process canvas with explicit material, electricity, heat, and consumable ports.
- Reusable desalination, electrolysis, DAC, Sabatier, ASU, Haber–Bosch, brine-mineral, chlor-alkali, bromine, aluminium, hydrogen-DRI steel, titanium, energy, storage, splitter, mixer, source, and destination blocks.
- A deterministic operating solver with capacity limits, bottleneck reporting, recycles, and visible balance residuals.
- A generic post-solve economics fold: source purchases, installed CAPEX, fixed and variable O&M, sale/disposal destinations, demand caps, replacements, delivered cost, NPV, and IRR. Screening **annual net cash** is capital-inclusive: `R − OPEX − annualized CAPEX` with `annualizedCapex = installedCapex × CRF(discountRate, projectLifeYears)`. NPV/IRR stay DCF (year 0 = `−installedCapex`; years 1..N = operating cash `R − OPEX` plus replacements — the annualized charge is not subtracted again).
- Editable economic assumptions on every source, converter, and destination, including zero-cost inputs for in-the-limit experiments.
- Captured-baseline scenario comparison and a synergy ledger for avoided purchases, avoided disposal, and added product revenue.
- Integrated methane + water-recycle, evidence-backed coastal methane, coastal methanol, and ammonia + brine industrial-hub examples. The coastal methane case binds Almería PVGIS solar, a cited Alboran multi-ion seawater assay (Millero/Pilson S=35 scaled to 36.5 g/kg; not a NaCl proxy), assumed intake, and unverified grid/freshwater/discharge to the plant, then dispatches a 24-hour typical day so night hours produce nothing unless a battery is assumed. The Mejillones methanol demo is a loadable electrolyzer + solid-sorbent DAC + SWRO + methanol plant on the Chile Atacama-coast preset (`mejillones-pvgis-2026-09-14`), with frozen PVGIS-ERA5 monthly yield (SARAH3 does not cover that longitude), the cited Atacama Pacific assay (Millero S=35 scaled 34.9/35), assumed intake, and unverified grid/freshwater/discharge. Synthesis electricity and methanol price stay screening. The Dead Sea hub cites the same PVGIS family, uses a frozen open-water ion assay, and marks freshwater and salt as assumed. Intake and discharge stay unverified inland. A literature assay is not a mineral concession. Minerals CAPEX uses the tea-screening DLE brine-throughput mid $12/(kg brine/day) (NREL OSTI 1782801 conversion; band $3–40). At that mid, Dead Sea demo scale is cash-positive because 4% fixed O&M tracks CAPEX (the old −$801k gate was the unsupported $80 OOM); high-band $40 stays cash-negative. Screening, not bankable. The abundance hub couples brine-derived bromide with chlor-alkali chlorine, then uses chlor-alkali hydrogen with ASU nitrogen for ammonia.
- Distinct DAC routes (solid-sorbent, liquid-solvent, electro-swing) with different heat and reagent contracts. Solid defaults sit in the IEA DAC 2022 S-DAC family with NASEM 2019 heat-dominated framing; liquid vectors cite Keith et al. 2018; electro-swing keeps Voskian cell-work electricity with screening capture/makeup. SWRO plant SEC 3.5 kWh/m³ / recovery 0.45 cites Elimelech & Phillip 2011 and Ghaffour 2013, with Voutchkov 2018 noted for best-in-class RO-train 2.5–2.8 kWh/m³. Sabatier ancillary 1 kWh/kg CH₄ stays screening in the Zapf/Baier band. Switching a route keeps compatible connections, does not rewrite an existing makeup chemical, and stays comparable against a captured baseline.
- Overview hero/metrics use `engine/uncertainty.js` quality (cited / recoverable / assumption / derived / screening) on cashflow, solar yield, land, and product rates: screening numbers use fewer significant figures, noisy screening chips stay off the dashboard, and a single not-bankable notice covers assumption-dominated **capital-inclusive** screening cash (R − OPEX − annualized CAPEX). Cited solar yield keeps the quality chip plus the PVGIS link and the monthly low–high band when a frozen monthly series is bound.
- A location bar: a Leaflet map picker plus coordinates. Click the map or Apply location to fetch or reuse PVGIS typical-day solar and bind it to the current factory. Toggle OSM, real Global Solar Atlas annual GHI LERC tiles (`GSA_IRRAD` ImageServer, `sliceId=2`, cited; hourly PVGIS still fetched on Apply location), WRI Aqueduct Baseline Water Stress tiles (UMN SCOPE MapServer, `{z}/{y}/{x}`, cited, with a screening GridLayer fallback), `estimateFootprint` campus polygons, and network plant markers. Solar, water, and land colormaps are mutually exclusive. Land is a cited choropleth of official agricultural land values in USD/ha (USDA NASS Land Values 2025 farm real estate by US state; Eurostat `apri_lprc` arable land by country including the UK 2018 row; Statistics Canada 32-10-0047-01 national farm land CAD/acre; ABARES/DAFF Farmland Price Indicator national broadacre AUD/ha — FX via documented ECB/Frankfurter rates) — early siting proxy only, not cadastral or parcel comps; transparent where unpublished (Chile, India, Gulf states, Japan, South Africa still have no official national $/ha series wired — ODEPA classified ads, NCA Japan farmland surveys, and Western Cape provincial transaction sheets are not the same class as NASS/Eurostat/StatCan/ABARES). If tiles or the map library fail, lat/lon still work. Site panels keep meteo cites, assay summaries, and rights chips (`authorized` / `assumed` / `unverified`) with a light `kind` (`grid` / `freshwater` / `intake` / `discharge` / `concession` / `purchase`). Unverified grid and freshwater stay explicit zeros until assigned (`authorize: false`); solve warns `unverified site right: KEY`. Size-to-target will not grow a resource whose right is unverified (`size-to-target cannot assume KEY`). Intake is not discharge; a concession is not a purchase.
- Cited inland/coastal **process-brine** assays (Abu Dhabi sabkha, Salar de Atacama Li, Lake Mackay WA, Great Salt Lake) sit beside the Millero seawater files. Geography-matched coasts bind both: Gulf presets get sabkha brine, Mejillones gets Atacama nucleus brine, Port Hedland gets Lake Mackay playa brine as WA salt-lake regional screening — seawater resources are not overwritten. `createAbundanceCase({ assayId, region })` (default `dead-sea-brine`, offtake `me-levant`) can run the minerals hub on those feeds; missing bromide is zero, not invented. Pass `region` from `site.region` (e.g. `Atacama/Chile`) so Chile Li offtake is not the Dead Sea cap. A literature assay is not a mineral concession.
- Discrete multi-site search (`searchAbundanceSites` / `node scripts/abundance-site-search.mjs`) scores the Dead Sea hub plus the preset catalog under the capital-inclusive cash gate. Abundance plants use each site's cited process-brine assay — not a Dead Sea chemistry clone — so Mejillones/Atacama Li, Gulf sabkha, Lake Mackay, Port Hedland, and Great Salt Lake are abundance-eligible (dual-assay coasts stay seawater-eligible too). Near-misses are the best **negative-cash operating** slates; idle (rate 0, no sale tonnes, cash≈0) does not rank. Default `rightsScenario` is `screening-assumes-intake-concession` (assumes intake/concession for evaluation only). `no-rights` does not assume those rights and skips/infeasibles plants that need them (`reason: no-rights`). `offtake-limited` keeps screening rights but tightens regional demand caps so ranking/cash can change. Not a permit. Screening TEA only: preset catalog, no real concessions. After cash>0 (and for near-misses), an optional `layerScore`/`softRank` from sun/water/land helpers may break ties when data exists — soft rank only, not a hard gate. Coastal/methanol misses may run a screening price×CAPEX `fuelProbe` inside tea-screening bands so fuels can rank cash+ when the band allows, else near-miss with bestCash/breakEvenPrice. Map layers are not optimizer objectives.
- Location presets for real candidate coasts and brine hubs: Gulf (Taweelah, Ras Laffan, plus desal-reject screening coasts), Texas/US Gulf (Corpus Christi), India (Mundra), Australia (Pilbara Port Hedland, Kwinana, inland Lake Mackay), North Africa (Agadir, Dakhla), Atacama/Chile (Mejillones), Red Sea (NEOM Oxagon, Ain Sokhna), Oman Duqm, Namibia Walvis Bay, Almería, and inland Great Salt Lake. Selecting a site sets coordinates, name, and honest unverified/assumed rights, then fetches live PVGIS. High-signal coasts bind a frozen Millero-scaled multi-ion seawater assay (Persian Gulf, Red Sea, Texas Gulf, Pilbara/Indian Ocean, Atacama Pacific, Morocco Atlantic, Arabian Sea / Duqm, Gulf of Kutch / Mundra, Benguela / Walvis Bay, Almería) into `site.assay` / `site.resources.seawater`. Basin or inverse-estuary typicals are not intake permits. Site search will not invent kWh/kWp: coastal/methanol evaluate only where a frozen per-site PVGIS series exists (Almería, Mejillones, Duqm, Mundra, Walvis Bay, Taweelah, Ras Laffan, Oxagon, Ras Al-Khair, Corpus Christi, Port Hedland, Agadir, Ain Sokhna); other assay coasts skip with `no-frozen-pvgis`. Abundance is not blocked by missing coastal PVGIS. These are map locations only — they do not replace the Almería coastal methane, Mejillones methanol, or Dead Sea abundance demos, and they are not bankable permits.
- Location-aware site footprint: solar land from panel area ÷ GCR (latitude-adjusted row spacing, NREL/SAM-style), plus **cited or screening** process-pad intensities (PEM, DAC, Sabatier, methanol, SWRO/MED, brine, ASU, Haber–Bosch, battery; MSF and electro-swing DAC remain screening). The Footprint map layer draws separate solar + pad polygons in a deterministic campus layout (not one total circle). Network `landHa` sums those site totals, not a flat 1.6 ha/MWp.
- Co-product positive-cashflow sizing (`sizeForPositiveCashflow`): maximize the number of sale sinks with revenue while capital-inclusive `annualNetCash > 0` (revenue-proportional allocation of OPEX + annualized CAPEX makes every active sale product share that sign); ties break by higher net cash. Physics sizing first; dollars only after `evaluateEconomics`. Plants with both brine minerals and a fuel converter (Sabatier, electrolyzer, methanol, or ammonia) search abundance, fuel, and joint families rather than an abundance-only early return. Default search is a coarse scale/rate grid, then a bounded refine (geometric mid) once a sign-change or best-negative bracket exists. Tests keep a fast path (`scales`/`rates` of length 1, or `refine: false`). Size-to-target remains the single-product physics tool. Dead Sea abundance is a screening TEA: at the $12 DLE mid, demo scale (1e5 kg brine/day) is cash-positive because fixed O&M tracks CAPEX — not a bankable offtake, and high-band $40 stays cash-negative.
- Iterative size-to-target: pick CH₄, H₂, methanol, ammonia, lithium, or salt and a kg/day rate. The outer loop sizes the loaded plant (desal, electrolyzer, DAC/Sabatier, methanol, ammonia, brine minerals, and PV as needed) until the operating solve is consistent. Every strategy with heat sinks/sources runs the T-feasible cascade inside duty estimation before buying residual heat or PV; leftover heat is screening electric resistance COP=1. The coastal demo remains a one-shot 37.5 kWp methane example until Size to target is used.
- A network rollup: multiple sited plants, product slate in t/year, land, optional haul corridors, and combined CAPEX/NPV. The fuels + minerals demo places solar methane at Almería and a brine/ammonia hub on the Dead Sea.

The Foundry source is concentrated in `engine/`, `cases/`, `js/flowsheet-app.js`, `index.html`, and `flowsheet.css`.

## Code map

- `index.html`, `flowsheet.css`, and `js/flowsheet-app.js`: editor, inspector, saved factories, and scenario comparison.
- `engine/model.js`: substances, streams, and graph validation.
- `engine/units.js`: process catalog and unit physics.
- `engine/solve.js`: operation, resource allocation, recycles, and balance diagnostics.
- `engine/heat.js`: post-solve temperature-feasible heat cascade (not HEN synthesis).
- `engine/economics.js`: costs and cash flows computed from the solved graph. Screening gate cash is `R − OPEX − annualized CAPEX`; NPV/IRR use upfront CAPEX + operating cash. Both economics panels use this result directly; IRR is a fractional rate.
- `data/tea-screening.js`: cited/screening TEA bindings. **Packs** (`packs[processId]`) hold `capexIntensity`, optional `capexIntensityBand` / `scaleExponent`/`refCapacity`, `fixedOmPercent`, `variableOm`, and evidence chips. Formula: `installedCapex = intensity × capacity × (capacity/ref)^(exponent−1)`, or `intensity × capacity` when the exponent is omitted. Minerals DLE intensity is a literature brine-throughput mid `$12/(kg brine/day)` with band `{low:3, mid:12, high:40}` (NREL TEA OSTI 1782801 / doi:10.2172/1782801 Table 3 Ventura IX ≈ $1.83 optimistic; same-table peer PEAs ≈ $4–15 converted the same way; multi-product Dead Sea hub ≠ Salton Sea Li-only DLE; screening OOM, not bankable). The old `$80` OOM is not supported by that conversion. Dead Sea demo scale is cash-positive at the $12 mid because 4% fixed O&M tracks CAPEX (even mid=20 stays cash+; high $40 is cash−) — not a drop to NREL $1.83. `bindCapexPack` / `bindCapex` apply that as `capexRate` (so CAPEX tracks sized capacity) except solar-PV, which precomputes `$/kWp`. **Demand caps** are regional offtake ceilings in kg/y (`demandByRegion` / `DEMAND_REGIONS`: `me-levant` default, `gulf`, `chile-atacama`, `australia`, `europe`, `india`, `texas`, `southern-africa`, `default`) — not plant offtake contracts. `resolveDemandRegion` maps `SITE_PRESETS.region` strings (Atacama/Chile, Levant, Gulf, Europe, India, Texas/US Gulf, Southern Africa, Australia, …) onto those ids. `bindSale(key, { region })`, `bindSaleForRegion(region)(key)`, and `getDemandForRegion(region)` set `annualDemandLimit`. Chile Li ceiling is a screening cap below USGS MCS 2025 Chile mine production 2024e ~49,000 t Li content — not the ME 1 kt cap and not an offtake contract; other regional minerals inherit ME with a note. Screening industrial-power overlays via `bindCost('power', { region })` (IEA Electricity 2024/2026 family, plus EIA Texas industrial average for `texas`; not a PPA). Li `unitPrice` stays the USGS LCE proxy in every region (Chile is supply-side). Regional CAPEX intensity multipliers (`capexMultiplierByRegion` / `getCapexMultiplierForRegion`) are screening labor/construction/EPC location proxies vs a US Gulf-ish baseline of 1.0 (India ~0.75, Levant ~0.85, Gulf ~0.90, Southern Africa ~0.95, Texas 1.0, Chile ~1.05, Australia ~1.15, Europe ~1.20; unmapped `default` omitted → 1). Turner & Townsend GCMI / World Bank ICP construction price levels / IRENA regional installed-cost family as direction; process equipment is traded so the construction spread is damped into ~0.7–1.3. Not plant quotes. NREL ATB is US-only. `bindCapexPack` / `bindCapex` apply the factor to `capexIntensity` when `extra.region` is set. `createAbundanceCase({ region })` is backward compatible (omit = me-levant). Site-search passes `site.region` into abundance TEA and rebinds fuel-plant sales/power purchases. Fuel CH₄ $1/kg is a screening green-premium (EIA Henry Hub is contrast only); methanol $0.40/kg is a commodity-band mid.
- `engine/footprint.js`: post-solve solar land (efficiency × location-aware GCR) and cited/screening process-pad intensities with evidence links.
- `engine/map-site.js`: map-picker geometry, footprint campus layout, layer cites, colormap helpers (GSA annual GHI ramp + geographic LERC tile math, Aqueduct BWS tile template), and `layerScoreAt` screening soft-rank helper. Not a permit, assay, cadastral layer, or surveyed layout. Solar overlay decodes Esri LERC via `vendor/LercDecode.js`.
- `engine/size.js`: outer product sizing loop (`sizeToProduct`) plus co-product cashflow search (`sizeForPositiveCashflow`). CH₄, H₂, methanol, ammonia, lithium, or salt demand sizes water, converters, brine, power, and `solarKWp`; `solveOperation` stays physics-only. Duty estimates cascade T-feasible waste heat onto process sinks before residual heat is purchased. `sizeToTarget` is the CH₄ wrapper. Positive-cashflow search refines the coarse `ABUNDANCE_SCALES` / `FUEL_RATES` (and site-search `SEARCH_SCALES` / `SEARCH_RATES`) after the first pass; `FAST_SCALES` / `FAST_RATES` skip refine.
- `engine/site-search.js` / `scripts/abundance-site-search.mjs`: discrete multi-site ranking. Assay-aware abundance (`createAbundanceCase({ assayId })`), operating near-misses, `searchAbundanceSites({ rightsScenario })` (`screening-assumes-intake-concession` default; `no-rights`; `offtake-limited`). CLI `--rights-scenario`. Preset catalog + Dead Sea hub only; optional map-layer `softRank` tie-break. Not a concession search.
- `engine/sensitivity.js`: screening fuel price/CAPEX break-even (`findFuelBreakEven`) and `probeFuelCash` (price × CAPEX grid inside tea-screening bands). Default path sizes the plant once at case capacities, then sweeps primary-product `unitPrice` ($/kg) or a CAPEX factor and re-scores `annualNetCash` / `scorePositiveCashflow` (no re-size). Prices and CAPEX are screening, not quotes. `node scripts/fuel-breakeven.mjs` prints JSON for coastal CH₄ and Mejillones methanol.
- `engine/uncertainty.js`: quality tags (`cited` / `recoverable` / `assumption` / `derived` / `screening`) and screening-precision formatters. No fake error bars.
- `cases/`: runnable reference plants (`coastal.js`, `methanol.js`, `abundance.js`, `sabatier.js`, `network.js`).
- `tests/*flowsheet*.test.js`: engine, economics, and browser-global/UI regression checks. `tests/map-site.test.js` covers the map-picker geometry and layer cites.
- `scripts/`: local server, static build, GitHub Pages deploy. `scripts/fuel-breakeven.mjs` prints screening CH₄/methanol price and CAPEX-factor break-even JSON.

The root page loads only the Foundry engine, cases, and UI scripts. `style.css` retains base styles used by Foundry. `flowsheet.html` redirects old links to the root page. The archived TEA page, JavaScript, and tests have been removed; their committed history remains in Git.


## Model limits

The operating model uses representative-day flows and fixed installed capacities. It checks component/element, charge, electricity, and heat accounting, but does not provide full thermodynamic closure, hourly storage dispatch, or economic optimization. Automatic plant sizing is a separate outer loop (`engine/size.js`) that chooses capacities and `solarKWp` from a product target (CH₄, H₂, methanol, ammonia, lithium, or salt), then calls the same operating solver. Process and cost presets are editable screening assumptions. Foundry money and land use fewer significant figures when screening; Overview and Economics each keep one not-bankable / screening notice instead of repeating screening chips on every metric.

## Running locally

Requires Node.js 18 or newer; no external runtime packages are needed.

- `npm run dev`: serve source files with caching disabled.
- `npm run build`: generate versioned deployment assets in `dist/`.
- `npm run preview`: serve the built output.
- `npm test`: run Foundry regression checks.
- `npm run deploy`: build `dist/` and publish it to GitHub Pages.

The live site is https://akarshgopal.github.io/ultimat-sim/ — pushes to main rebuild via GitHub Pages.
